# Damped-Oscillator-Laboratory

## Project Description
A numerical simulation environment studying the physics of linear, nonlinear, and coupled harmonic oscillators. The engine explores thermodynamic balancing, generalized normal modes, and complex phase-space attractors.

## Physics Equation
The core physics engine supports linear multi-mass matrices, Duffing dynamics, and the non-conservative Van der Pol equation:
$$\ddot{x} - \mu(1-x^2)\dot{x} + x = F(t)$$

## Features
*   **Physics Engine:** Numerical simulation via `solve_ivp` supporting stiff adaptive solvers (BDF, Radau) necessary for complex non-linear dynamics.
*   **Self-Sustained Oscillations:** Analyzes the Van der Pol oscillator, detecting stable Limit Cycles and calculating non-conservative energy-like diagnostic limits ($E_{ref}$).
*   **Relaxation Dynamics:** Simulates and maps parameter sweeps across $\mu$ regimes, analyzing transitions from near-sinusoidal harmonic limits to stiff relaxation oscillations.
*   **Nonlinear Dynamics Lab:** Analyzes the Duffing Oscillator, executing numerical continuation to visualize multistability, jumps, and hysteresis.
*   **Coupled Normal Modes:** Maps multi-degree-of-freedom generalized eigenvalues to trace Lissajous-style superpositions and beating.
*   **Spectral Analysis Lab:** Fast Fourier Transform (FFT) analysis, detecting higher-order harmonics generated by nonlinear distortions.
