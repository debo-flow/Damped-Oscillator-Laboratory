# Damped-Oscillator-Laboratory

## Project Description
A numerical simulation environment to study the physics of linear and nonlinear harmonic oscillators. The engine bridges time-domain integration, frequency-domain signal processing (FFT), matrix coupled dynamics, and nonlinear Duffing behaviors.

## Physics Equation
The core physics engine supports linear multi-degree-of-freedom systems, as well as the nonlinear Duffing equation:
$$m\ddot{x} + b\dot{x} + kx + \alpha x^3 = F(t)$$

## Features
*   **Physics Engine:** Numerical simulation using `scipy.integrate.solve_ivp` supporting singular, coupled, and non-homogeneous nonlinear systems.
*   **Nonlinear Dynamics Lab:** Analyzes the Duffing Oscillator, distinguishing hardening ($\alpha > 0$) and softening ($\alpha < 0$) behaviors.
*   **Hysteresis & Jump Phenomena:** Executes numerical continuation techniques (Forward/Backward sweeps) to visualize multistability and nonlinear resonance bending.
*   **Harmonic Signal Processing:** Utilizes the FFT module to identify higher-order odd harmonics generated by the cubic cubic distortion.
*   **Energy & Phase-Space:** Tracks generalized nonlinear potential energy ($U \propto x^4$) validating non-conservative work balances.
*   **Automated Testing:** `pytest` regression suite ensuring absolute backward equivalence (when $\alpha=0$), energy conservation, and robust boundary warnings.
